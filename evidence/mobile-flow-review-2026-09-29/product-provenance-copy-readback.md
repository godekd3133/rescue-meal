# 상품 정보 출처 이력 문구 readback

## 변경

- 출처 이력의 행 제목을 `상품 정보 저장 / 변경 / 삭제`에서 `상품 정보 출처 저장 / 변경 / 삭제`로 구체화했습니다. 상품명·브랜드·분류 수정 이력과 출처 자체 변경 이력을 구분합니다.
- 적용 행의 세부 문구에서 중복되던 `상품 정보`를 줄여 `공개 상품 정보에서 가져왔어요.`처럼 출처와 행동만 남겼습니다.
- `Open Food Facts`나 `공개 상품 DB` 대신 앱의 기존 소비자용 표현 `공개 상품 정보`를 사용합니다. 게스트 작성자는 앱의 다른 계정 이전 문구와 일치하도록 `게스트 기록`으로 표시합니다.
- Connected test의 기대 문구를 현재 사용자용 표현과 맞췄습니다.

## 검증 상태

- `npm run build`: 통과, 보호 런타임 28개 파일, Vite 771개 모듈.
- `git diff --check`: 통과.
- 출처 이력 화면의 Playwright 상호작용 검증은 실행하지 않았습니다. 이번 턴 허가 범위 밖의 화면 흐름이며, 기록 변경·출처 삭제 동작을 실행하지 않도록 멈췄습니다. 따라서 화면 캡처와 connected E2E는 `not-run`입니다.
