# 홈 날짜 확인 진입 포커스 및 CSS 정리 readback

## 변경

- 홈의 `포장지 날짜를 살펴볼 식품` 요약은 기존처럼 검색어·보관 위치 조건을 초기화하고 `날짜·보관 확인` 필터를 선택한 상태로 식품 목록에 이동합니다.
- 이동 스크롤이 끝난 뒤 선택 필터로 포커스를 옮겨, 키보드·보조기기 사용자가 화면 밖의 홈 요약 버튼에 머물지 않게 했습니다.
- `prototype.spec.ts`의 기존 홈 요약 회귀에 선택 필터 포커스 기대값을 추가했습니다.
- 현재 JSX와 테스트에서 생성되지 않는 레거시 CSS 선택자만 제거했습니다. 연결·날짜·보관 상태처럼 런타임에서 동적으로 조합되는 클래스는 유지했습니다.

## 근거와 검증 상태

- 소스 확인: `openNeedsReviewInventory()`는 필터를 설정한 뒤 `openInventory()`로 재고 위치를 열고, `restoreContentNavigation()`은 앱의 스크롤 영역을 목록 시작점으로 이동시킵니다. 기존 코드에는 그 뒤 대상 필터에 포커스를 옮기는 처리가 없었습니다. 이는 소스 기반 발견이며, 이전 실제 포커스 위치를 브라우저에서 확인한 것은 아닙니다.
- 현재 검증: `npm run build` 통과, 모바일 런타임 보호 28개 파일 통과, Vite 771개 모듈 변환, `git diff --check` 통과.
- 브라우저 회귀: 새 포커스 기대값은 추가했지만 실행하지 않았습니다. 화면 흐름의 Playwright 상호작용·캡처 허가가 확인되지 않아 runtime 상태는 `not-run`입니다.
- 번들: 현재 CSS 330.8KB / 예산 260KB. 기준은 변경하지 않았습니다. 생산자 없는 레거시 선택자를 누적으로 약 3.4KB 줄였지만 예산 초과는 남아 있습니다.
- 사용자 기록, 소비 상태, 검색 데이터는 변경하지 않았습니다.
