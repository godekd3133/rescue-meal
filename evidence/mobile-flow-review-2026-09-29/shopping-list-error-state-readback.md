# 장보기 목록 오류 상태 readback — 2026-09-29

## 확인한 혼선

목록 읽기 실패 시 원인은 로그인 만료일 수도 있고 서버/응답 실패일 수도 있는데, 빈 장보기 목록의 안내가 늘 `인터넷에 연결한 뒤`라고 단정했습니다. 또 아직 목록을 읽지 못한 상태에서 진행 수가 `0/0`으로 표시되고, CSS는 그 상태를 구매 완료 색상으로 표현했습니다. 오류는 실제 네트워크 단절과 구분되어야 하고, 읽지 못한 목록을 빈 목록이나 완료로 보여주면 안 됩니다.

## 반영

- 진행 상태 문구를 순수 함수 `getShoppingListProgressCopy`로 분리했습니다.
- 빈 목록 오류는 `아래 안내를 확인하고 다시 시도해 주세요.`로 안내해 아래의 원인별 오류와 재시도 버튼으로 연결합니다.
- 아직 읽지 못한 목록에서는 분모·분자를 표시하지 않고, 접근성 이름도 `장보기 목록 상태`로 바꿉니다. 로딩/오류를 중립 표면으로 유지하고 구매 완료 색은 실제로 항목이 모두 확인된 목록에만 적용합니다.
- 기존 구매 중/완료 상태 문구와 숫자는 유지했습니다.
