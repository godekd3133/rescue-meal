# 모바일 식품 찾기 바로가기 개선

## 참고한 카카오페이 패턴

- [카카오페이 맞춤형 홈 소개](https://story.kakaopay.com/121-kakaopay-home-2/)는 자주 쓰거나 지금 필요한 기능을 홈 상단에서 빠르게 찾게 하고, 중요한 금융 일정을 제때 보여주는 방향을 설명합니다.
- [카카오페이 검색 기능 소개](https://contents.kakaopay.com/contents/694)는 상단 검색으로 서비스와 혜택을 찾는 진입점을 소개합니다.
- Rescue Meal에는 시각 스타일을 복제하지 않고, 식품 찾기 진입점을 바로 보이게 하는 정보 구조 원칙만 적용했습니다.

## 바뀐 점

- 기존 `전체 식품 보기`를 돋보기 아이콘이 있는 `식품 찾기`로 바꿨습니다. 동작은 기존과 같게 유지해 식품 목록의 검색창으로 연결되며 새 화면이나 별도 라우트는 만들지 않았습니다.
- 이동 직후 키보드를 강제로 열지 않습니다. 320px·393px 모바일 폭 모두 검색창이 보이는 위치에 도착하고, 사용자가 원할 때 입력을 시작합니다.
- 날짜 의미나 안전 안내, 기록 저장 동작에는 변경이 없습니다.

## 확인 결과

- [변경 후 홈 화면 캡처](04-home-food-finder-after-393x852-dark.png): 다크모드, 393×852. 바로가기 터치 영역은 94×44px로 확인했습니다.
- 식품 찾기 버튼이 검색창으로 연결되고 키보드는 자동으로 열리지 않는지 320px·393px에서 확인했습니다.
- 식품 검색 결과 흐름, 홈 진입점 키보드 포커스 링(라이트·다크), 모바일 런타임 무결성 검사를 통과했습니다.
- `npm run build` 통과: TypeScript, Vite 771개 모듈, 보호 런타임 28개 파일 무결성 통과.
- 남은 문제: `npm run check:bundle`은 CSS 333.8KB / 예산 260KB로 실패합니다. 이번 변경은 CSS를 늘리지 않았지만 예산 초과는 해결되지 않았습니다.
